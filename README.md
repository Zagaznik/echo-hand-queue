# Echo Hand Queue

Модуль Foundry VTT: кнопка поднятой руки на левой панели сцены. Игрок выбирает тип заявки, ГМ получает плавающее окно с очередью портретов персонажей.

## Возможности

- Кнопка `Заявка Мастеру` на левой панели сцены.
- Три типа заявки:
  - Не срочная заявка
  - Срочная заявка
  - Вмешаться прямо сейчас
- У ГМ появляется перемещаемое и изменяемое по размеру окно.
- В окне видны портрет персонажа, имя персонажа, имя игрока и цвет заявки.
- При наведении на карточку дублируется тип заявки.
- Крестик рядом с портретом удаляет конкретную заявку.
- Если заявок больше нет, окно ГМ закрывается само.
- Один игрок может иметь только одну заявку. Повторная отправка обновляет статус заявки.
- Публичное сообщение в чат при отправке заявки.
- Звук заявки у игрока и у ГМ.

## Установка

1. Распаковать папку `echo-hand-queue` в `FoundryVTT/Data/modules/`.
2. Перезапустить Foundry VTT.
3. Включить модуль в мире.

## Настройки

В настройках модуля можно включить/выключить звук, изменить путь к звуку и громкость.
